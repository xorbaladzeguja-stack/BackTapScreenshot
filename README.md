# Back Tap Screenshot — Android აპლიკაცია

აპი ცდილობს ტელეფონის უკანა მხარეს ორმაგი დაკაკუნების ამოცნობას აქსელერომეტრით და სქრინშოტის შენახვას Android-ის MediaProjection API-ით.

## APK-ის აწყობა GitHub Actions-ით

1. ატვირთე პროექტის შიგთავსი GitHub-ის `main` branch-ზე.
2. გახსენი **Actions** და გაუშვი **Build Android APK** workflow.
3. წარმატებული გაშვების ბოლოს ჩამოტვირთე `BackTapScreenshot-debug-apk` Artifact.
4. ამოარქივე ZIP და დააინსტალირე `app-debug.apk`.

## გამოყენება

1. გახსენი აპი და დააჭირე **ნებართვის მიცემა და დაკაკუნების ჩართვა**.
2. Android-ის სისტემურ ფანჯარაში აირჩიე **მთელი ეკრანი** და დააჭირე **დაწყება**.
3. დატოვე აპის მუდმივი შეტყობინება აქტიური; სანამ MediaProjection სესია მუშაობს, სენსორი უსმენს დაკაკუნებას.
4. ჯერ დააჭირე **ტესტური სქრინშოტი**. თუ სურათი შეინახა `Pictures/BackTapScreenshot` საქაღალდეში, ეკრანის გადაღება გამართულია.
5. შემდეგ ტელეფონის უკანა მხარეს ორჯერ მსუბუქად დააკაკუნე. მგრძნობელობა შეცვალე სლაიდერით.

## მნიშვნელოვანი შეზღუდვები

- საჭიროა Android 9 (API 28) ან უფრო ახალი და აქსელერომეტრი.
- MediaProjection-ის თანხმობა სისტემური ნებართვაა. Android-ის ვერსიის მიხედვით სესიის შეწყვეტის ან აპის ხელახლა გაშვების შემდეგ შეიძლება ხელახლა დადასტურება გახდეს საჭირო.
- Android-ის ეკრანის არჩევის ფანჯარაში აირჩიე **მთელი ეკრანი**. მხოლოდ ერთი აპის არჩევისას სხვა აპებზე გადასვლის შემდეგ სქრინშოტი შეიძლება შავი ან ცარიელი იყოს.
- აპი არ იყენებს Accessibility-ს, ინტერნეტს, კამერას, მიკროფონს ან მდებარეობას.
- დაკაკუნების ამოცნობა დამოკიდებულია ტელეფონის სენსორზე, ქეისზე და დარტყმის ძალაზე. მგრძნობელობა რეგულირებადია.
- HONOR/MagicOS-მა შეიძლება ფონური სერვისი გააჩეროს. თუ ასე მოხდა, აპს მიეცი ფონური მუშაობის/ავტომატური გაშვების უფლება და გამორთე მისთვის ბატარეის მკაცრი შეზღუდვა.
- ეს კოდი უნდა აიწყოს GitHub Actions-ში და შემოწმდეს კონკრეტულ მოწყობილობაზე; ყველა HONOR/MagicOS ვერსიაზე მუშაობის გარანტია წინასწარ ვერ გაიცემა.
