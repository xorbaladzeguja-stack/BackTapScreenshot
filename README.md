# Back Tap Screenshot — Android აპლიკაცია

ეს არის პირველი ვერსიის პროექტი: ტელეფონის უკანა მხარეს ორი მკვეთრი დაკაკუნების ამოცნობა და Android-ის სისტემური Screenshot ბრძანების გამოძახება.

## როგორ მივიღოთ APK Android Studio-ს გარეშე

1. GitHub-ზე შექმენი ახალი **Private repository** (პირადი საცავი).
2. ამ ZIP-ის შიგთავსი ამოარქივე და პროექტის ყველა ფაილი ატვირთე საცავში ისე, რომ `.github/workflows/build-apk.yml` გზაც შენარჩუნდეს.
3. გახსენი საცავის **Actions** ჩანართი.
4. აირჩიე **Build Android APK** და დააჭირე **Run workflow**. პირველი `main` branch-ზე ატვირთვაც ავტომატურად გაუშვებს აწყობას.
5. დასრულებულ workflow run-ში ჩამოტვირთე **BackTapScreenshot-debug-apk** Artifact.
6. ტელეფონში ამოარქივე Artifact ZIP და დააინსტალირე `app-debug.apk`.

GitHub Actions APK-ს ღრუბელში ააწყობს; კომპიუტერზე Android Studio არ გჭირდება. მიღებული APK არის debug-ხელმოწერილი, პირადი ტესტირებისთვის.

## ტელეფონზე ჩართვა

1. გახსენი **Back Tap Screenshot** აპი.
2. დააჭირე **წვდომის პარამეტრების გახსნა**.
3. Android-ის Accessibility სიაში მოძებნე **Back Tap Screenshot** (ზოგ მოწყობილობაზე „Installed apps“ ან „Downloaded apps“ განყოფილებაში) და ჩართე.
4. დაბრუნდი აპში და დააჭირე **ჩართვა**.
5. ტელეფონის უკანა მხარეს ორჯერ დაკაკუნე. საჭიროებისამებრ შეცვალე მგრძნობელობა.

თუ HONOR/MagicOS წერს, რომ პარამეტრი უსაფრთხოების გამო შეზღუდულია, აპის App info გვერდზე შეამოწმე **Allow restricted settings**. ზოგი MagicOS ვერსია გვერდიდან დაყენებულ ყველა აპს ამ გამონაკლისს არ აძლევს.

## მოთხოვნები და შეზღუდვები

- Android 9 (API 28) ან უფრო ახალი და აქსელერომეტრი.
- სქრინშოტისთვის საჭიროა მომხმარებლის მიერ ხელით ჩართული Accessibility სერვისი. აპი იყენებს Android-ის `GLOBAL_ACTION_TAKE_SCREENSHOT` ბრძანებას.
- სენსორების ფონურ რეჟიმში წასაკითხად მუშაობს მუდმივი შეტყობინების მქონე foreground service.
- აპს არ სჭირდება ინტერნეტი, კამერა, მიკროფონი ან მდებარეობა; ეკრანის ტექსტსა და შიგთავსს არ კითხულობს.
- HONOR-ის ენერგიის დაზოგვის პარამეტრებმა შეიძლება ფონური სერვისი გააჩეროს. საჭიროების შემთხვევაში აპს მიეცი Background activity / Auto-launch უფლება და გამორთე მისთვის ბატარეის მკაცრი შეზღუდვა.
- დაკაკუნების ამოცნობა სენსორის მიხედვით განსხვავდება. ქეისმა, ტელეფონის დაჭერამ და მაგიდაზე დადებამ შეიძლება მგრძნობელობაზე იმოქმედოს.
- ეს საწყისი ვერსია ჯერ არ დატესტილა ზუსტად შენს HONOR 9D / MagicOS 10 მოწყობილობაზე. მწარმოებლის შეზღუდვამ შეიძლება Accessibility-ის ჩართვა ან ფონური მუშაობა დაბლოკოს.
